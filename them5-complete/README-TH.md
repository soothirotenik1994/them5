# The M5 Residence — เว็บจองห้องพักและระบบหลังบ้าน

## เริ่มใช้งาน

ใช้ Node.js 22.18 ขึ้นไป (แนะนำ Node.js 24) เปิด Terminal ในโฟลเดอร์นี้:

```sh
npm install
npm run build
npm start
```

เว็บลูกค้า: http://localhost:3000 — หลังบ้าน: http://localhost:3000/admin
ครั้งแรกสร้างบัญชี Super Admin ด้วยตัวเอง รหัสผ่านอย่างน้อย 10 ตัวอักษร ไม่มีรหัสผ่านเริ่มต้น
หากใช้ pnpm: `pnpm install --ignore-scripts`, `pnpm run build`, `pnpm start`
สำหรับพัฒนา: `npm run dev`

## ตั้งค่าก่อนเปิดรับลูกค้า

1. ตั้งค่าโรงแรมหลัก: ชื่อ ที่อยู่ เบอร์โทร และเปิด/ปิดรับจอง
2. จัดการประเภทห้องพัก: ราคา ความจุ **จำนวนห้องที่เปิดขาย** และภาพห้อง (ค่าเริ่มต้น 1 ห้องต่อประเภท ต้องแก้ให้ตรงโรงแรม)
3. กำหนดวันปิดรับจองและคูปองตามต้องการ
4. แจ้งเตือน / ตรวจสลิป: ตั้งบัญชีรับโอนหรืออัปโหลด QR จริง พร้อม Email และ LINE
5. ใบเสร็จ / ใบกำกับภาษี → ข้อมูลผู้ออกเอกสาร: ตรวจข้อมูลบริษัทตามภาพตัวอย่างและอัปโหลดโลโก้จริง

ใช้รูปจากไฟล์แนบแทนรูปที่ต้องดึงจาก Directus ไม่ได้เชื่อมฐานข้อมูล Directus เดิม รายการกิจกรรมและเนื้อหาที่นำเข้าควรตรวจความเป็นปัจจุบันก่อนเผยแพร่

## การจองและรับชำระ

- ตรวจจำนวนห้องทุกคืน รวมวันปิดรับจอง คำนวณราคาฝั่งเซิร์ฟเวอร์
- บันทึกสำเร็จจึงออกเลขอ้างอิง เริ่มสถานะ Pending ไม่แสดงสำเร็จลวงเมื่อออฟไลน์
- ลูกค้าเปิด `/booking` กรอกเลขจองและอีเมลเพื่อตรวจสถานะและแนบสลิปแจ้งโอน
- หลังบ้าน → แจ้งเตือน / ตรวจสลิป → เปิดสลิป ตรวจยอดเข้าบัญชี แล้วรับชำระหรือปฏิเสธ
- ยอดอนุมัติครบยอดจองจึงเปลี่ยนเป็น Paid ไม่ได้ตรวจยอดธนาคารอัตโนมัติ
- เจ้าหน้าที่เปลี่ยน Confirmed / Checked-In / Completed / Cancelled ได้ แต้มสมาชิกเพิ่มครั้งเดียวเมื่อ Completed
- Pending นับเป็นห้องที่ถูกจองไว้จนกว่าเจ้าหน้าที่จะยกเลิก ยังไม่มีการหมดอายุอัตโนมัติ

## Email

หน้า **แจ้งเตือน / ตรวจสลิป** กรอก SMTP Host, Port, Username, Password หรือ App Password, ชื่อผู้ส่ง และอีเมลผู้ส่ง
Port 465 เปิด SSL/TLS; Port 587 ไม่เปิดสวิตช์ SSL/TLS ตั้งแต่เชื่อมต่อ
อีเมลผู้รับหลายคนคั่นด้วย comma เปิด Email และเลือกเหตุการณ์การจองใหม่/แจ้งโอน/ส่งอีเมลรับเรื่องให้ลูกค้า
**บันทึกก่อนกดส่งอีเมลทดสอบ**

## LINE

ใช้ **LINE Messaging API ของ LINE Official Account** เนื่องจาก LINE Notify ยุติบริการแล้ว

1. ใช้ OA ของโรงแรมที่เปิด Messaging API
2. กรอก Channel access token และผู้รับ `userId` / `groupId` / `roomId`
3. เพิ่ม OA เป็นเพื่อน หรือเชิญ OA เข้ากลุ่ม และเปิดให้บอทเข้ากลุ่มใน LINE Developers Console
4. ถ้าต้องการรับ ID ผ่าน Webhook ให้กรอก Channel secret และ URL เว็บไซต์จริงในระบบ
5. ตั้ง Webhook URL ใน LINE Developers เป็น `https://ชื่อโดเมน/api/line/webhook` และเปิด Use webhook
6. ส่งข้อความหา OA หรือในกลุ่ม แล้วรีเฟรชหน้าตั้งค่าเพื่อเลือก ID ที่พบ ระบบตรวจลายเซ็นก่อนบันทึก
7. เปิด LINE กดบันทึก แล้วส่ง LINE ทดสอบ

localhost รับ Webhook จาก LINE ไม่ได้จนกว่าจะมี HTTPS URL สาธารณะ
การส่งขึ้นอยู่กับ Token สิทธิ์ OA ผู้รับ และโควตาข้อความ
คู่มือ: https://developers.line.biz/en/docs/messaging-api/sending-messages/

### ประวัติและการลองใหม่

คิวแจ้งเตือนถูกบันทึกพร้อมรายการจอง/แจ้งโอนก่อนติดต่อผู้ให้บริการ แยกงานต่อช่องทางและผู้รับ
ส่งไม่สำเร็จจะลองใหม่อัตโนมัติรวมสูงสุด 3 ครั้ง และมีปุ่มลองใหม่
LINE ใช้ Retry Key เดิม; SMTP ใช้ Message-ID เดิม แต่ผู้ให้บริการอีเมลอาจส่งซ้ำเมื่อระบบหยุดหลังรับคำขอแล้ว
สถานะสำเร็จหมายถึงผู้ให้บริการรับคำขอ ไม่ใช่ผู้รับเปิดอ่านหรืออีเมลเข้ากล่องหลัก

## ใบเสร็จรับเงิน / ใบกำกับภาษี

1. ตรวจรับเงินและตั้งการจองเป็น Paid (หรือ Checked-In / Completed หลังรับเงินแล้ว)
2. เมนู **ใบเสร็จ / ใบกำกับภาษี → ออกใบกำกับภาษี**
3. เลือกการจอง กรอกข้อมูลผู้ซื้อ ที่อยู่ เลขผู้เสียภาษี สาขา วันที่ และรายละเอียดห้อง/เลขห้อง
4. ราคาเป็นราคารวม VAT ยอดรวมต้องตรงยอดจอง คำนวณตัวอักษรอัตโนมัติ
5. ดูตัวอย่าง A4 แล้วออกเอกสารและเปิดพิมพ์
6. เลือก A4 สเกล 100% ปิด Header/Footer ของเบราว์เซอร์ แล้วพิมพ์หรือ Save as PDF

แบบฟอร์มมีหัวบริษัท ตารางลูกค้า รายการ จำนวน ราคา ยอดก่อนภาษี VAT ตัวอักษร และลายเซ็นตามภาพ
โลโก้ตั้งต้นเป็นตัวอักษร M5 สามารถอัปโหลดโลโก้จริงได้
เลขรันแยกเดือน เช่น `NO.0069-09-001` ตามปี พ.ศ. ในวันที่เอกสาร
ออกหนึ่งฉบับที่ไม่ยกเลิกต่อการจอง พิมพ์ซ้ำใช้เลขเดิม การแก้ข้อมูลบริษัทไม่เปลี่ยนเอกสารเก่า
ข้อมูลผิดให้ยกเลิกพร้อมเหตุผลแล้วออกใหม่ เก็บประวัติและไม่ใช้เลขซ้ำ
เป็นเอกสารพิมพ์/PDF ไม่ใช่ระบบนำส่ง e-Tax Invoice หรือเชื่อมกรมสรรพากร

## ข้อมูลและติดตั้งจริง

- `db.json` เขียนผ่านไฟล์ชั่วคราวแล้วเปลี่ยนชื่อ ใช้ Node.js **หนึ่ง process ต่อฐานข้อมูล** ห้ามหลาย instance แชร์ไฟล์
- `uploads/` เป็นภาพสาธารณะ ส่วน `private-slips/` เปิดสลิปได้ผ่าน API ผู้ดูแลเท่านั้น
- ปุ่มสำรองข้อมูลดาวน์โหลด JSON ต้องสำรอง uploads และ private-slips เพิ่มด้วย ไฟล์สำรองมีข้อมูลบัญชีและการตั้งค่า
- กู้คืนโดยหยุดเซิร์ฟเวอร์ แล้วแทน db.json และโฟลเดอร์ภาพด้วยชุดสำรองเดียวกัน
- Session หมดอายุ 8 ชั่วโมง ต้องล็อกอินใหม่หลังรีสตาร์ต รหัสผ่านบัญชีใช้ scrypt
- คัดลอก `.env.example` เป็น `.env` เพื่อกำหนด PORT, HOST และ COOKIE_SECURE
- ระบบจริงใช้ HTTPS reverse proxy, `COOKIE_SECURE=true` และดิสก์ถาวร สร้างผู้ดูแลก่อนเปิดสู่อินเทอร์เน็ต
- SMTP/LINE เก็บฝั่งเซิร์ฟเวอร์ ไม่มีบัญชีจริงแนบมา ต้องกรอกก่อนแจ้งเตือนจริง
